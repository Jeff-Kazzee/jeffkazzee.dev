Vivary is no longer actively maintained. I built it as an installable workspace shell for agent work, with plain Markdown and YAML underneath.

## What it tried to solve

Agent work gets hard to follow when the files, rules, and checks are scattered. Vivary put those pieces in one workspace without requiring a large framework.

## What it included

- A `create-vivary` command for starting a workspace
- A typed knowledge graph through Tropo
- Graph-aware review through Ozone
- Coordination surfaces through Exo
- Plain Markdown and YAML files underneath

## The repository

The repository remains available for anyone who wants to inspect the approach or run the old code. It is a historical project, not an actively maintained product.
