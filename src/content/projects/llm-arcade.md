Eleven browser games in one arcade, with high scores, achievements, and badges across the rack. Games arrive as they pass playtest.

No human wrote the code. Agents did, working under a written set of rules and a review loop. My job was running that process, not typing.

## The games

Brickstorm, Gem Columns, Hyper Circuit, Kickflip City, Lastwatch, Munch Maze, Run 'n' Gunner, Rune Ruin, Sky Defense, Starfall Squadron, and The Undervault.

## Why games

Games make a claim about AI agents that you can check yourself. Either the collision detection works and the frame rate holds, or it doesn't. Writing about agent capability proves nothing. Playing a game they built proves something.

The repository keeps the process next to the code: the rules the agents work under, the patterns they follow, a running devlog, and a decision log.

## Status

A pre-launch preview, open to play. Scores and streaks already count. A list of fixes stands between it and finished.
