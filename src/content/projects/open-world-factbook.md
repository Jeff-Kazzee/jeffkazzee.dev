An open-source country database covering 262 countries and territories at [worldfactbook.xyz](https://worldfactbook.xyz).

Open data should not require an API key or paywall. The site and its dataset are open source, so visitors can browse the factbook or inspect the repository.

I like this one because it is deliberately unflashy. It is a public dataset, a usable site, and a repository anyone can inspect.
