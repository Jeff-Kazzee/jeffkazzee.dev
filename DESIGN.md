# Design

Night gallery. The site is a dark observatory room where shipped work glows on the walls, anchored by a full-bleed Earthrise hero. Awe is the register. Elegance is the finish. Replaces the short-lived warm-paper light system (2026-06-12, same day) at Jeff's direction after seeing the Earthrise artwork.

## Visual Theme

- Register: brand (portfolio)
- Theme: dark, night-sky. The Earthrise render (`src/assets/earthrise.avif`) sets the mood: black sky, gray-brown regolith, blue Earth.
- Color strategy: Restrained on dark. Tinted near-black neutrals, plus one jade-green accent (the matured neon green of the original identity), used for links, primary actions, and the live-status dot.

## Color Palette (OKLCH)

| Token | Value | Role |
|---|---|---|
| `--bg` | `oklch(15% 0.012 255)` | page background (night sky) |
| `--bg-raised` | `oklch(18% 0.014 255)` | footer band, code blocks, badges |
| `--surface` | `oklch(19.5% 0.015 257)` | cards |
| `--ink` | `oklch(93% 0.008 95)` | headings, body (warm moonlight white) |
| `--ink-soft` | `oklch(76% 0.012 95)` | secondary text |
| `--ink-faint` | `oklch(62% 0.014 95)` | captions, metadata |
| `--line` | `oklch(30% 0.015 255)` | hairline borders (1px, never slabs) |
| `--accent` | `oklch(78% 0.11 155)` | jade: links, active nav, primary buttons |
| `--accent-bright` | `oklch(86% 0.1 152)` | accent hover (brighter, not darker, on dark) |
| `--accent-vivid` | `oklch(72% 0.17 150)` | live-status dot only |
| `--accent-tint` | `oklch(30% 0.05 155)` | selection, washes |
| `--amber` | `oklch(76% 0.12 80)` | wip/demo status |

Never `#000`/`#fff`. Backgrounds tint cool (hue ~255, night); text tints warm (hue ~95, moonlight).

## Typography

- Display + prose: **Literata** (variable). Headings wght 520–600, no uppercase.
- UI + captions: **Hanken Grotesk** (variable).
- Google Fonts CDN with preconnect. No npm font packages.
- Hero h1 scales to `clamp(2.8rem, 6.5vw, 4.75rem)` for awe; interior h1 stays `clamp(2.4rem, 5.5vw, 3.75rem)`.
- Body line-height 1.75 (light-on-dark needs extra leading). Measure: 66ch.

## Hero (home)

Full-bleed Earthrise: an absolutely positioned `<Image>` cover at object-position center 70%. A vertical scrim carries the page background at the top for the header seam, then deepens toward the bottom for text. Content sits bottom-left over the regolith. Live-status line, big serif headline with a soft text-shadow, lede, profile links. `min-height: clamp(36rem, 92vh, 54rem)`.

## Components

- **Cards**: `--surface`, 1px `--line`, 10px radius. Hover lifts the card 2px, with a deep soft shadow and a jade-tinted border.
- **Buttons**: pills. Primary: jade bg, near-black text. Quiet: hairline border, ink text.
- **Status**: dot plus uppercase sans label. Shipped is jade, wip/demo/alpha is amber, deprecated is a hollow grey ring so retired work does not read as work in progress. The live dot pulses (`breathe`).
- **Metric panel**: a fallback for cards with no screenshot. It fills the same slot at the same 16/10 ratio, with a large serif number over a small uppercase label on `--bg-raised`. A shelf of mixed cards still reads as one row, and the slot carries an exact number instead of decoration.
- **Badges**: `--bg-raised` pills, no borders.
- **Images**: 10px radius, hairline border. Screenshots are the exhibits.
- **OG card**: generated by `scripts/generate-og.mjs` from the Earthrise art; already matches this theme.

## Layout & Spacing

Site max 70rem. The home page is three shelves of image-led cards: community resources, open tools, then side projects. Cards without a screenshot fall back to the metric panel. Sections breathe: `clamp(3.5rem, 9vh, 5.5rem)` heading margins.

## Motion

- Ease `cubic-bezier(0.22, 1, 0.36, 1)`, 200 to 550ms.
- `.rise` staggered entrance on hero lines. `.reveal` scroll fade-up, gated behind `html.js` so no-JS readers see everything, with a 700ms safety net that reveals anything on screen if the observer never fires. No content may depend on either running.
- Full `prefers-reduced-motion` support.

## Bans carried from PRODUCT.md

Monospace as voice, `$` prompts, glitch effects, marquee, neon-on-black harshness (jade is soft, not neon), hard offset shadows, side-stripe borders, uppercase headings, gradient text.
